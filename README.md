# CãoMetria — App de cuidado para creches de cães

> Case de entrevista para vaga de **Product Manager**: visão de produto, recorte da
> primeira fatia e protótipo funcional.

**A visão:** nenhum cuidado é esquecido. Cada pet tem um **prontuário**; o sistema
transforma esses prontuários na **rotina do dia**; e uma **linguagem visual de triagem**
(verde / amarelo / vermelho) mantém o risco de cada animal sempre à vista.

A primeira fatia priorizada é o **Painel de Triagem do dia**: check-in, painel das
tarefas de dieta e medicação, conclusão de tarefa, alertas de dose atrasada e
check-out com bloqueio.
